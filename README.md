# Exotic Pet Keeper

A mobile-friendly application for managing exotic pets,
feeding records, and enclosure environmental conditions.

## Project Overview

This project is developed for the Programming 5 course
at the University of Pécs.

The system demonstrates a microservice architecture
consisting of four independent backend services:

1. Data Management Service
2. Enclosure Service
3. Sensor Service
4. Notification Service

The application uses REST APIs for communication and
WebSocket technology for real-time environmental alerts.

## Technologies

- JavaScript
- Node.js
- Express.js
- WebSocket (ws)
- SQLite
- HTML and CSS
